Facial recognition access control that runs entirely on the local machine. An operator enrolls a person through the camera, the system stores the face encoding, and scanner mode matches live frames against that database to identify who is in front of the device. Users flagged as administrators trigger a customizable Key function that can release an electronic lock.

The problem

A university project in 2023: enroll faces through a camera and release a lock only for authorized people. It was my first serious Python code, written by hand before AI coding tools — and it won among 60 projects.

Decisions

  1. 01

    A hook for the hardware

    When an administrator is recognized, the system calls a customizable key() function — the integration point for locks and turnstiles.

  2. 02

    v3.0 with no compiler

    In 2026 I rebuilt the engine on OpenCV's own neural models (YuNet + SFace in ONNX): dlib, CMake and Visual Studio are gone, leaving opencv-python and numpy — on Windows, Linux, macOS and Raspberry Pi.

  3. 03

    Legacy preserved

    The 2.5 version from university stays in the repository exactly as it was written; 3.0 lives next to it, with a new interface and a one-click .exe.
