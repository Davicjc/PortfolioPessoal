Every point of presence with its routers, OLTs, switches and APs — and the customers attached to each one. Concurrent ICMP pings with latency, loss and history, a topology map, a REST API for everything and backups ready to go.

The problem

The network was watched in MikroTik's The Dude: a closed Windows program with no API. Finding out which customers depended on a device that went down meant cross-checking screens and spreadsheets.

Decisions

  1. 01

    Async pinging

    Concurrent ICMP tests with asyncio in a FastAPI backend, storing latency, loss and history per device.

  2. 02

    From POP to customer

    The data model links POP → device → customer, so an outage immediately shows who is affected.

  3. 03

    Built to be operated

    SQLite in development and PostgreSQL in production, a systemd service behind Nginx, plus backup (pg_dump + JSON, 30 days) and health-check scripts.
