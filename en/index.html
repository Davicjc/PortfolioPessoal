03

How I work

  1. 01

    I start where the work happens

    Before opening the editor I watch the technician in the field, the NOC on a call and the manager planning the day. The system has to fit their routine — much of NexusAtlas came from requests made in the office hallway.

  2. 02

    Security lives in the data layer

    Role permissions are enforced in database rules, not just hidden in the UI. Integrations with critical systems are read-only and allow-listed. scrypt for passwords, HttpOnly sessions, CSP with no inline scripts.

  3. 03

    Measure before claiming

    The speed test counts uploads on the server because browsers overestimate them — and it was checked against a line capped at 940/470 Mbps: it measured 938.7/468.8. A number shown to a customer has to be verifiable.

  4. 04

    Clients aren't held hostage

    Accounts in the client's name, near-zero cloud cost and a step-by-step guide in every project — from a blank Firebase to a one-command installer — so the business can run it without depending on me.
